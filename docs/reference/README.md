# Reference Material

## Approved Needle design inspiration

[`needle-design-inspiration.jpg`](needle-design-inspiration.jpg) is the approved visual-direction reference from the initial Needle planning work.

Use it for:

- overall editorial feeling;
- album-art prominence;
- asymmetric composition;
- scale contrast;
- open spacing;
- cover shelves/walls;
- typography hierarchy;
- restrained archival details.

Do **not** treat it as a literal page specification or trace every module. The image includes conceptual content and layout ideas that may not map one-to-one to the final information architecture.

The written design contract in [`../DESIGN.md`](../DESIGN.md) takes precedence when a detail in the image is ambiguous.

Explicitly ignore any visual element that conflicts with the accepted written direction, including fake player/vinyl UI or overly literal retro treatment.
